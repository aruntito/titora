# TITORA Public Status

This page records the status vocabulary and the distinction between documented intent and verified implementation.

## Status vocabulary

| Status | Meaning |
| --- | --- |
| **Concept** | Idea, research direction, or early definition. |
| **Planned** | Concrete direction identified, but implementation is not verified here. |
| **Implemented** | Implementation exists in the owning project and has been verified by the maintainer. |
| **Verified** | A specific behavior or milestone has been explicitly tested or otherwise verified. |
| **Production** | The maintainer has explicitly established that the relevant system is in production use. |

Documentation alone does not move a project into **Implemented**, **Verified**, or **Production**.

## Ecosystem-level state

TITORA is an index, documentation, and public architecture surface. It should not imply that every listed project has the same maturity or deployment state.

Project-specific maturity belongs to the owning repository.

## Reporting status

When updating this page or the project map:

- use evidence from the owning public repository where available
- identify the project and scope of the claim
- distinguish current state from roadmap
- avoid inferring production status from code presence alone
- do not turn conceptual relationships into implementation dependencies
