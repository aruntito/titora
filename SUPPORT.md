# Support

TITORA is a public map of Arun Tito's personal technology projects. Projects listed here are independent and may be experimental, research-oriented, private in implementation, or not production-ready.

## Where to ask

For a question about a specific project, open an issue in that project's public repository when issues are enabled.

For questions about this TITORA index, project relationships, public documentation, or broken links, open an issue here.

## Before opening an issue

Please check the relevant README, documentation, owning repository, and existing issues.

For documentation problems, include the affected page or section and what appears to be incorrect.

## Important distinction

A project being listed by TITORA does not mean that it shares code, infrastructure, deployment, runtime state, or production status with another project.
